# 여주초등학교 교원연수 웹교안 — 2차 (스킬 중심)

클로드 스킬과 코워크 2시간 연수 교안입니다. 강사 이애진(FlowDX).

1차(코워크 중심)와는 **구성이 다른 별도 판**입니다. 둘 중 하나를 고르셔서 쓰시면 됩니다.

## 1차와 무엇이 다른가

| | 1차 | 2차 (이 판) |
|---|---|---|
| 중심 | 코워크 | **스킬** |
| 전원 실습 | 코워크 실습 여러 개 | **스킬 하나 만들기 + 폴더 하나 맡기기** |
| 무료 계정 | 대부분 못 따라옴 | **스킬은 무료에서 다 됨** |
| 탭 수 | 11개 | **8개** |

## 깃허브 페이지로 올리는 법

1. 깃허브에서 새 저장소를 만듭니다. **Public**으로 만들어야 무료로 페이지가 열립니다.
2. 이 폴더 안의 것을 **전부** 올립니다 — `index.html`, `README.md`, `.nojekyll`, `files` 폴더.
3. 저장소 → `Settings` → 왼쪽 `Pages`
4. `Source`를 **Deploy from a branch**, 브랜치는 **main**, 폴더는 **/ (root)** 로 두고 `Save`
5. 1~2분 뒤 주소가 열립니다.

**1차 교안과 같은 저장소에 올리지 마세요.** 둘 다 `index.html`이라 덮어씁니다.
따로 올리시려면 저장소를 하나 더 만드시거나, 이 폴더를 `v2` 같은 하위 폴더에 넣으세요.

## ⚠️ 올리기 전에 꼭 읽어 주세요

**깃허브 페이지는 누구나 볼 수 있는 공개 웹사이트입니다.**
암호를 걸어 두었지만 그건 **가림막이지 잠금장치가 아닙니다.** 페이지 소스를 보면 암호가 보이고,
`files/` 안의 압축 파일은 주소만 알면 암호 없이도 받을 수 있습니다.

`files/` 폴더에는 **여주초등학교에서 실제로 받은 문서**가 들어 있습니다
(공문, 가정통신문 발송본, 선도학교 계획서·보고서 양식).
학생 이름과 동의서·명렬표는 전부 가상 자료이지만, **학교 문서는 진짜입니다.**

셋 중 하나를 고르셔야 합니다.

- **그대로 올린다** — 연수 기간에만 올려 두고, 끝나면 저장소를 지우거나 Private으로 바꿉니다.
- **학교 문서를 뺀다** — `3_공문안내.zip` · `4_가정통신문.zip` · `5_계획서.zip` · `5_보고서.zip` ·
  `여주초_연수실습자료.zip`을 지우고 올립니다. 그 버튼들만 안 열리고 나머지는 그대로 됩니다.
- **안 올린다** — 아티팩트 링크만 쓰십니다. 그쪽이 가장 안전합니다.

## 고치고 싶을 때

`index.html` 한 파일에 전부 들어 있습니다. 올린 뒤에도 그 파일만 바꿔서 다시 올리면 됩니다.
